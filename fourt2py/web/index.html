FOURT.F

FOURT.F is Norman Brenner's classic mixed-radix Fast Fourier Transform. Drag the knots below to set the amplitude of each harmonic; a transliteration of FOURT.F compiled to WebAssembly transforms that frequency-domain spectrum into a 200-sample time-domain waveform — 200 is deliberately not a power of two, so the demo exercises FOURT's general mixed-radix path rather than the textbook radix-2 case. The result is traced on the oscilloscope and looped through the Web Audio API.

Each knot's Y position is split across its FFT bin and that bin's conjugate (k and N-k), so FOURT's inverse transform (ISIGN=+1) hands back a real-valued signal with no imaginary leftovers to discard.
